## 🚀 Featured project

### 📄🐱 [DocToText](https://github.com/anndemchuk/DocToText)
A Mac app that turns **PDF, Word, PowerPoint, and images into plain text and Markdown** — fully offline.
Drag a file in, get clean text out. Big files are processed in batches, and images are read with local OCR.

`Electron` · `Node.js` · `pdf.js` · `mammoth` · `Tesseract.js`
